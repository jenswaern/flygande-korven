# Flygande Korven – efter lektion 1

Den här menyn motsvarar referensen från slutet av lektion 1. Använd den om du missade lektionen eller saknar en projektmapp att fortsätta med.

## Kom igång

1. Packa upp hela ZIP-filen.
2. Öppna mappen `flygande-korven` i VS Code.
3. Öppna `index.html` i Chrome eller med Live Server.
4. Fortsätt i den här mappen under lektion 2.

## Filerna

- `index.html`: färdig meny med rubriker, logga, lista, dagens tips, telefonnummer och öppettider.
- `style.css`: CSS från slutet av lektion 1.
- `menu.txt`: textunderlaget till menyn.
- `assets/flygande-korven-logo.png`: logotypen som används i HTML-filen.

Under lektion 2 sparar och granskar vi ändringar med GitHub Desktop, undersöker sidan med DevTools och bygger vidare med flexbox.

Har du redan arbetat med en egen meny fortsätter du i din befintliga projektmapp.
